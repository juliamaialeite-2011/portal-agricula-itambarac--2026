### 📖 Descrição do Projeto

Portal web informativo e tecnológico sobre o município de **Itambaracá - PR**, destacando sua identidade cultural, força na agricultura e desenvolvimento da pecuária local.

O projeto une a **tradição do campo com a inovação digital**, servindo como vitrine para a comunidade e estudantes, conscientizando os jovens sobre a importância do agronegócio em Itambaracá.

---

## 🎯 Objetivos

✅ Conscientizar os jovens sobre a importância do agronegócio em Itambaracá  
✅ Valorizar o trabalho do homem do campo  
✅ Mostrar como a tecnologia é aliada da sustentabilidade rural  
✅ Preservar e divulgar a cultura local  
✅ Criar oportunidades de aprendizado sobre desenvolvimento rural

## 🚀 Como Rodar Localmente

### Requisitos
- Navegador web moderno (Chrome, Firefox, Safari, Edge)
- Nenhuma dependência externa necessária!

### Passos

1. **Clone o repositório**
   ```bash
   git clone https://github.com/juliamaialeite-2011/portal-agricula-itambarac--2026.git
   cd portal-agricula-itambarac--2026
   ```

2. **Abra o arquivo index.html**
   - Duplo clique em `index.html` no explorador de arquivos
   - Ou abra com seu navegador favorito
   - Ou use um servidor local (veja abaixo)

3. **Usando um servidor local (Recomendado)**

   **Com Python 3:**
   ```bash
   python -m http.server 8000
   ```
   Acesse: `http://localhost:8000`

   **Com Python 2:**
   ```bash
   python -m SimpleHTTPServer 8000
   ```

   **Com Node.js (http-server):**
   ```bash
   npx http-server
   ```

   **Com Live Server (VS Code):**
   - Instale a extensão "Live Server"
   - Clique com botão direito em `index.html`
   - Selecione "Open with Live Server"
